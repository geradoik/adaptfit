# Design deliverable

Keep the exported wireframes here so the design upload and the repo agree.

| What | File | Notes |
|---|---|---|
| All frames, one per page, in flow order | `wireframes.pdf` | Figma: select all frames on the Wireframes page, File > Export, PDF. Put your name and ID on the first page. |
| Prototype click-through | `prototype-walkthrough.mp4` (optional) | Screen recording of Present mode, in case "capture screen time" means a recording. |
| Figma link | `figma-link.txt` | Set sharing to "Anyone with the link can view" and test it in a private window. |

Frame list and tap connections: `docs/prototype-flows.md`. The app skeleton in `frontend/src/flows.js` follows the same map; `npm run check:flows` fails if they drift apart.
